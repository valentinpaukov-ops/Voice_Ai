# Voice Ai — как добавить запись в эфир

## Как добавить выпуск (30 секунд)

1. Откройте на GitHub папку **`audio`**.
2. Нажмите **Add file → Upload files**, перетащите аудиофайл, нажмите **Commit changes**.
3. Всё. Через минуту запись появится на сайте в очереди эфира.

Ничего больше делать не нужно: робот сам пропишет файл в список эфира
(`audio/manifest.json`) и сам сделает коммит.

## Как назвать файл

Порядок в эфире — по алфавиту имён файлов. Поэтому ставьте в начало дату или номер:

```
2026-09-21_Итоги недели.mp3
2026-09-22_Новый офис в Алматы.mp3
01_Утренний брифинг.mp3
```

Название на сайте получится из имени файла: дата и номер отбрасываются,
подчёркивания превращаются в пробелы. Русские буквы и пробелы — можно.

Если у файла заполнены теги (Название/Исполнитель), возьмутся они.

## Как поправить название, автора или рубрику

Откройте `audio/manifest.json` прямо на GitHub (карандашик) и поменяйте текст:

```json
{
  "file": "2026-09-21_Итоги недели.mp3",
  "title": "Итоги недели: продукт и релизы",
  "host": "Анна Волкова, продуктовая команда",
  "tag": "Дайджест",
  "duration": 760
}
```

Ваши правки **не затираются** при загрузке новых файлов — робот их бережёт.

Поле `tag` — это рубрика, она видна на карточке и участвует в поиске:
`Дайджест`, `Подкаст`, `Шоу`, `Плейлист`, `Гайд` — любая.

## Как убрать запись из эфира

Удалите файл из папки `audio` — робот сам вычистит его из списка.

## О чём помнить

| Ограничение | Значение |
|---|---|
| Размер сайта на GitHub Pages | до 1 ГБ |
| Один файл в репозитории | до 100 МБ |
| Трафик | 100 ГБ в месяц |

Главное: **git хранит все версии навсегда**. Удалённый из папки файл перестаёт
играть, но место в репозитории продолжает занимать. Поэтому лучше сразу
сжимать записи в MP3 128–192 кбит/с — час эфира весит около 60 МБ,
а в хорошем качестве занял бы в разы больше.

Когда записей станет много (больше ~500 МБ), имеет смысл перенести аудио во
внешнее хранилище — в манифесте вместо имени файла можно указать полную
ссылку `https://...`, страница это понимает без всяких переделок.

## Что где лежит

```
index.html                         сайт радио
audio/                             сюда кладём аудиозаписи
  manifest.json                    список эфира (робот ведёт сам)
tools/build_manifest.py            скрипт, который собирает список
.github/workflows/build-manifest.yml  робот, запускающий скрипт
```

## Если список не обновился

Откройте вкладку **Actions** в репозитории — там видно, отработал ли робот.
Можно запустить вручную: Actions → «Обновить манифест эфира» → **Run workflow**.

Один раз нужно разрешить роботу делать коммиты:
**Settings → Actions → General → Workflow permissions → Read and write permissions**.

## Как включить сам сайт

**Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.**
Адрес появится там же через пару минут.
