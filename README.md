# Voice Ai — резервная копия сайта

Корпоративное радио «Технологии Доверия». Здесь — резервная копия сайта для слушателей: эфир, новости, архив,
«Для меня», промо-ролик и виджет, с материалами на 9 октября 2026.

Основная работа идёт в корпоративном GitLab и на стенде компании; там же публикация, согласование новостей,
сборщики и озвучка — для них нужен сервер, на GitHub Pages они не работают.
