Новости для Voice Ai

Загрузить новости

Подойдёт любое из трёх: JSON от агента (вставить текст или файл), файл Word (.docx) или обычный текст с новостями. Из Word и текста страница сама нарежет карточки, подскажет теги и найдёт, нет ли такой новости уже на сайте. Всё можно поправить в карточках. Новость можно и написать вручную кнопкой «+ Добавить новость».

Отправка

Где взять токен (для выпускающего)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Voice_Ai.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Скопируйте токен и вставьте выше. Подойдёт и тот же токен, что вы вводите на самом сайте в режиме редактора.
