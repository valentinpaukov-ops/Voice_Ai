# Доступ для редакторов новостей: настройка (один раз, около 5 минут)

Редакторам не нужны ни аккаунт GitHub, ни токены, ни вы в роли посредника. Вы даёте им **адрес формы и код доступа**. Редактор вводит код вверху страницы, нажимает «Активировать», готовит новости и отправляет их выпускающему. Новости попадают в блок «на согласовании» на платформе.

## Как это устроено

- Сайт у нас статический, сервера нет, поэтому отправлять в репозиторий можно только с помощью токена GitHub (ключа).
- Ключ для редакторов лежит в репозитории **только в зашифрованном виде** (файл `docs/news-sender-access.json`). Шифрует его код доступа. Форма расшифровывает ключ в браузере, когда редактор вводит код; сам ключ нигде не показывается.
- Ключ ограничен **отдельным репозиторием очереди**, а не сайтом. Даже если ключ попадёт не в те руки, им можно только добавлять файлы в очередь: сайт, аудио и новости он изменить не может, а опубликовать новость может только выпускающий.

## Шаги

1. **Создайте репозиторий для очереди.** На GitHub: New repository. Имя, например, `Voice_Ai_inbox`. Выберите **Private** и поставьте галочку **Add a README file** (без неё репозиторий пустой, и запись в него не сработает).
2. **Создайте токен для редакторов.** GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Срок на ваше усмотрение. **Repository access: Only select repositories → выберите только `Voice_Ai_inbox`.** Permissions → Repository permissions → **Contents: Read and write**. Скопируйте токен (начинается с `github_pat_`).
3. **Добавьте очередь в свой токен.** Откройте токен, которым вы подключили платформу (тот же раздел Fine-grained tokens → Edit) и добавьте в Repository access ещё и `Voice_Ai_inbox` (Contents: Read and write). Иначе вы не увидите присланное.
4. **Платформа → режим редактора → «Доступ для редакторов».** Проверьте имя репозитория очереди, вставьте токен из шага 2. Код доступа подставится сам (длинный и случайный; менять его на короткий не стоит). Нажмите **«Создать доступ»**.
5. Платформа проверит токен, зашифрует его и запишет файл. Она покажет **адрес формы и код доступа**: отправьте их редакторам.

Дальше всё как обычно: редакторы присылают, вы видите новости в блоке «на согласовании» и публикуете или отклоняете.

## Про код доступа

- Файл с зашифрованным ключом лежит в публичном репозитории, поэтому его может скачать кто угодно и пробовать подобрать код у себя на компьютере. **Короткие и угадываемые коды (`admin`, `1234`, имя компании) подбираются за секунды**, после чего ключ становится известен. Длинный случайный код (по умолчанию 12 знаков) подобрать практически невозможно. Платформа предупредит, если вы введёте слабый.
- Именно поэтому ключ ограничен репозиторием очереди: в худшем случае посторонний сможет положить мусор в очередь (вы его просто отклоните).
- Код видите только вы: кнопка «Показать код» в этом же окне (хранится на устройстве, где вы создавали доступ). Если код потерян, создайте доступ заново: новый токен и новый код.
- Редактор вводит код один раз, браузер его запомнит на этом устройстве. У всех редакторов один и тот же код; имя редактор вписывает сам и оно попадает в подпись «от <имя>». Подпись не проверяется: для 1–2 доверенных людей этого достаточно.

## Если нужно отозвать доступ

В том же окне нажмите **«Отозвать доступ»**: файл доступа удалится, форма перестанет принимать код. После этого **обязательно отзовите и сам токен** на github.com/settings/tokens: старая зашифрованная копия остаётся в истории репозитория, и если код когда-нибудь станет известен, по ней можно будет достать ключ. Чтобы сменить код, нажмите «Создать доступ» заново: новый токен, новый код, старый токен отзовите.

## Если редакторы не могут отправить

- «Код не подошёл»: проверьте код (регистр важен). Если вы пересоздавали доступ, редакторам нужен новый код.
- «Ключ доступа больше не действует»: токен истёк или отозван; создайте доступ заново.
- В любом случае у формы есть запасной путь: **«Скачать файл для выпускающего»**. Файл открывается на платформе: режим редактора → «Загрузить новости (Word, JSON, текст)».
