# Необязательно: ретранслятор Google Apps Script (альтернатива основному способу)

> Основной способ настройки проще и не требует Google: см. `access-setup.md` (зашифрованный ключ в репозитории и код доступа). Ретранслятор нужен, только если вы хотите, чтобы у каждого редактора был свой код и имя подставлялось сервером, а не вписывалось самим редактором. Если в `news-sender-config.json` указан адрес ретранслятора, он имеет приоритет над основным способом.

Один раз, около 10 минут. Нужен аккаунт Google (любой, например ваш рабочий).

## Что получится

Редактору достаточно открыть ваш единственный адрес страницы, ввести выданный вами код и нажать «Отправить на проверку». Новости попадут в очередь «на согласовании» на платформе. Токен GitHub хранится только в настройках скрипта (у вас): на страницу и к редакторам он не попадает. Скрипт умеет писать только файлы `inbox/news-….json`, ничего другого в репозитории он изменить не может.

## Шаги

1. Откройте https://script.google.com → **Новый проект**. Удалите всё, что там есть, и вставьте содержимое файла `news-relay.gs`. Назовите проект, например «Voice Ai: новости».
2. Слева **Настройки проекта** (шестерёнка) → внизу **Свойства скрипта** → **Добавить свойство**. Добавьте:
   - `GITHUB_TOKEN`: токен GitHub. Создайте его на https://github.com/settings/personal-access-tokens/new (Fine-grained): Repository access → Only select repositories → **Voice_Ai**; Permissions → Repository permissions → **Contents: Read and write**. Лучше отдельный токен под этот скрипт, а не тот, что вы вводите на сайте.
   - `EDITORS`: коды доступа и имена в виде JSON. Например: `{"A7K4Q9":"Анна Волкова","M2X8P5":"Иван Петров"}`. Код придумайте сами: 6–10 случайных букв и цифр, у каждого редактора свой. Имя из этой таблицы увидит выпускающий в блоке «на согласовании»: подделать его нельзя.
3. Вверху **Развернуть → Новое развёртывание** → шестерёнка рядом с «Выбор типа» → **Веб-приложение**. Поля: «Запуск от имени»: **Я**; «У кого есть доступ»: **Все**. Нажмите **Развернуть**, разрешите доступ (Google попросит подтвердить права: нужно разрешение на запросы к внешним сервисам). Скопируйте **URL веб-приложения** (оканчивается на `/exec`).
4. Проверка: вставьте этот URL в адресную строку браузера. Должен появиться текст `{"ok":true,"service":"voiceai-news-relay"}`.
5. Впишите URL в файл `docs/news-sender-config.json` репозитория (на GitHub откройте файл → карандаш → Commit):
   ```json
   {
     "relay": "https://script.google.com/macros/s/…/exec"
   }
   ```
   Через минуту страница редактора покажет поле «Код доступа» и кнопку «Отправить на проверку».
6. Отправьте редактору адрес страницы `https://valentinpaukov-ops.github.io/Voice_Ai/docs/news-sender.html` и его код. Больше ничего.

## Если что-то меняется

- **Новый редактор или отозвать доступ:** отредактируйте `EDITORS` (удалите строку с кодом). Действует сразу.
- **Заменить токен GitHub:** обновите `GITHUB_TOKEN`.
- **Обновили код скрипта:** Развернуть → Управление развёртываниями → карандаш → Версия: **Новая версия** → Развернуть. Адрес не меняется.

## Защита и пределы

- Без кода доступа ничего не принимается. Неверный код замедляет ответ на 1,5 секунды (подбор становится очень долгим): поэтому код должен быть не из цифр «1234».
- Принимается не больше 40 новостей за раз и 300 за день; заголовок до 200 знаков, описание до 1500. Лишние поля отбрасываются.
- Имя редактора берётся из таблицы кодов, а не из присланных данных.
- Если редактор не может отправить (скрипт недоступен), у страницы есть запасной путь: «Скачать файл для выпускающего». Выпускающий открывает такой файл на платформе: режим редактора → «Загрузить новости (Word, JSON, текст)».
- Любой, у кого есть адрес `/exec`, может отправить запрос, но без кода он ничего не запишет. Адрес лежит в публичном файле конфигурации, поэтому полагайтесь на код, а не на «секретность» адреса.
- Квоты Google для бесплатного аккаунта (число запусков и время работы в сутки) для 1–2 редакторов избыточны.
